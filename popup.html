      How it works: Sync reads X's bookmarks API and reconciles
      against your manifest + Chrome's download history. Nothing is downloaded yet — instead
      a pending list is shown for review. Click Download all to fetch the new media,
      or Discard to skip. The run lives in the background service worker, so you can
      close and reopen this popup any time without losing progress.


      Open x.com/i/bookmarks first so the extension can
      capture your session, and disable
      Ask where to save each file in chrome://settings
      to avoid Save dialogs.
